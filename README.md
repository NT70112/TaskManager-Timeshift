# TimeShift

**TimeShift** — одностраничное веб-приложение для управления задачами, разработанное с использованием **React**.

Приложение содержит список задач и таймер, работающий по принципу техники **Pomodoro**.

Для демонстрации работы цикла таймер был настроен на 10 секунд рабочего времени и 5 секунд отдыха.

## Что было реализовано

### 1. Таймер

**1.1.** При запуске начинается цикл, который чередует рабочую фазу и время отдыха.

**1.2.** Остановка не сбрасывает таймер, поэтому можно делать паузы. При нажатии на кнопку функция внутри `Timer` обновляет значение для последующего отсчёта с точки остановки. Для сброса предусмотрена отдельная кнопка, которая активна только в период, когда таймер неактивен.

**1.3.** Нажатие кнопки `Start` на задаче сбрасывает таймер и запускает новый цикл.

### 2. Задачи

**2.1.** При создании задачи формируется объект с уникальным `id`, названием и описанием. Объекты задач объединяются в массив, который используется в качестве источника данных для отображения списка задач.

Для сохранения данных применяется `localStorage`. Массив преобразуется в JSON и записывается в локальное хранилище браузера. При повторном открытии приложения сохранённые данные извлекаются из `localStorage` и преобразуются обратно в JavaScript-массив. После восстановления данных обновляется состояние React.

**2.2.** Задачи можно удалять. Удаление реализовано фильтрацией текущего массива по ключу (`id`).

**2.3.** Выполнение задачи визуализируется с помощью галочки.

### 3. Интерфейс

**3.1.** Реализована адаптивная вёрстка с поддержкой экранов шириной от 500 px.

**3.2.** Предусмотрено переключение фона страницы на тёмную тему.

### 4. Запуск приложения

Для запуска проекта используется **Vite**.

Установить зависимости проекта:

```bash
npm install
```

Запустить локальный сервер:

```bash
npm run dev
```
